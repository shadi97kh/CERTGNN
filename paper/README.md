# Building the paper

`neurips_2026.tex` is the paper. It `\input`s:

- `tex/*.tex` — the five table fragments, generated by `experiments/make_tables.py`
- `appendix.tex` — supplementary sections, generated by `experiments/make_appendix.py`
- `figures/*.pdf` — generated by `experiments/make_figures.py` and
  `experiments/make_workflow_figure.py`

Regenerate everything before a submission build:

```
python experiments/make_tables.py
python experiments/make_figures.py
python experiments/make_workflow_figure.py
python experiments/make_appendix.py
```

## The style file is missing, and this is deliberate

`neurips_2026.sty` is **not in this repository**. It is the workshop's file and
has to be downloaded from the ICBINB / NeurIPS 2026 call. Without it the paper
does not compile at all.

`pagecount_proxy/neurips_2026.sty` is **not that file**. It is a stand-in that
reproduces only the text-block geometry (5.5in x 9in on US Letter, 10pt) and
the handful of commands the paper uses, so that page count can be measured
before the real style file is available. Float spacing and section skips are
close but not identical, so treat any count from it as accurate to roughly a
third of a page. Never submit a PDF built with it.

To measure the page count:

```
mkdir -p /tmp/pagecount && cp neurips_2026.tex appendix.tex /tmp/pagecount/
cp -r tex figures /tmp/pagecount/
cp pagecount_proxy/neurips_2026.sty /tmp/pagecount/
cd /tmp/pagecount && tectonic -X compile neurips_2026.tex --outdir .
```

Measured with the proxy at the last regeneration: **8 pages** for the main text
including references, which begin on page 8; **14 pages** including the
appendix.
