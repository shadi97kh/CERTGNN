## Single weakest point

**The recorded G2 PASS rests on exchangeability of the calibration and test splits (A2.5 / A-EXCH), which holds only because the synthetic generator draws both from one process — no code checks it, and the same experiment can be pointed at a shifted test split (`SyntheticConfig.shift_eta0_mean`) while still calling `split_conformal_quantile`, with no warning.** Second: the scores in that run came from the oracle mechanism, not from a trained model, so the theorem's link-correction has been demonstrated on the generative link rather than on a GNN head; the model-side half of A2.1 (heads return logits) is enforced by construction but has not yet been exercised by any faithfulness score.
